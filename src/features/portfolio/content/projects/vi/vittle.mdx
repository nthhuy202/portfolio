## Vấn đề

Sản phẩm lên thực đơn hiện có chạy trên stack đã cũ — React class components trên Meteor/Node 8 — đã tích tụ nhiều bug, luồng đặt hàng không còn khớp yêu cầu mới của khách hàng, và màn hình admin chưa theo kịp mô hình dữ liệu.

## Trách nhiệm

Sửa các bug hiện có ở cả user site lẫn admin, cập nhật UI theo mockup mới, viết lại logic đặt hàng theo yêu cầu mới, và xây lại trang quản lý đơn hàng cùng thông tin người dùng. Triển khai tính năng admin mới thích ứng với dữ liệu đã thay đổi — tất cả vẫn trong codebase class-component/Meteor cũ thay vì viết lại từ đầu.

## Kết quả

Bàn giao cùng team 3 người, giữ cho sản phẩm lên thực đơn đang chạy production tiếp tục phát triển mà không cần migrate toàn bộ khỏi stack cũ.
