## Vấn đề

Khách hàng cần một cách để theo dõi hiệu quả kinh doanh trên nền tảng Mirakl Marketplace — đơn hàng, doanh thu, tồn kho — mà không phải lục tìm trong giao diện admin gốc của nền tảng.

## Cách tiếp cận

Xây dựng các component UI từ mockup, tích hợp API để quản lý vòng đời sản phẩm (biến thể, số lượng), và trực quan hóa dữ liệu bán hàng, tồn kho qua biểu đồ động ApexCharts.

## Kết quả

Bàn giao cùng team 3 người, mang lại cho khách hàng một dashboard duy nhất cho dữ liệu đơn hàng, doanh thu và tồn kho thay vì phải tự tổng hợp từ admin gốc của nền tảng.
