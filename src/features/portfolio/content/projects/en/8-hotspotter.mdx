## Problem

The objective was to build a promotional web platform for Hotspotter, a mobile app (iOS/Android) focused on discovering and sharing user-generated places. The core business goal was to drive user acquisition (app downloads) by offering a highly interactive, visual preview of the app's core feature—a dynamic spatial map—directly on the web.

## Responsibilities

The engineering team architected the web application using Next.js, integrated the MapBox API for interactive spatial data visualization, and ensured a fluid, responsive UI across all device sizes.

## Challenges & Solutions

- **Interactive Map Performance (Spatial Data Visualization):** MapBox relies on WebGL, which is heavily resource-intensive. Improper integration within a React/Next.js environment often triggers redundant re-renders, causing memory leaks and severe UI jank when panning or zooming.
  - **Solution:** The team implemented isolated state management for the map instance, decoupling the MapBox WebGL context from the standard React render lifecycle. By leveraging React Refs and precise Memoization, we ensured that only the specific GeoJSON markers updated upon user interaction, preventing full DOM re-renders and guaranteeing a buttery-smooth mapping experience.

- **Balancing Heavy Interactivity with SEO:** Heavy client-side map integrations typically degrade SEO performance, which is detrimental to a landing page heavily reliant on organic discoverability.
  - **Solution:** Capitalized on Next.js’s Hybrid architecture. The team utilized Server-Side Rendering (SSR) / Static Site Generation (SSG) for all critical textual content and SEO metadata, ensuring immediate search engine indexing. Conversely, the heavy MapBox component was dynamically imported (Lazy Loaded) strictly on the client side. This cleanly resolved the SEO vs. Performance trade-off.

## Result

Successfully built a highly engaging, performant promotional platform. The flawless MapBox integration provided users with an intuitive preview of the app's value proposition, directly supporting marketing campaigns and driving app installation conversions.
