## Problem

The client required a dynamic, animated promotional website (using AOS) that strictly adhered to Web Accessibility (a11y) and Semantic HTML standards. Simultaneously, their core product—an AI Chat Bot—needed to be engineered as an embeddable widget capable of being seamlessly integrated into any third-party host website.

## Responsibilities

Led the Frontend architecture and development for both modules: the heavily optimized static landing page (HTML/CSS) and the VueJS-based Chat Bot SDK.

## Challenges & Solutions

- **Strict WCAG Compliance & Technical SEO:** The client demanded a flawless DOM structure that accommodated screen readers and maximized search engine visibility without compromising visual animations.
  - **Solution:** Engineered a strict Semantic HTML5 architecture. I thoroughly implemented ARIA roles, robust focus management, and optimized AOS animation triggers to ensure the site was not only visually engaging but also achieved perfect Lighthouse scores for SEO and Accessibility.

- **Architecting an Embeddable Widget (Plug-and-Play):** The VueJS chat application had to function as a standalone library. The major risk was CSS bleeding and global state conflicts when injecting the widget into unpredictable host environments.
  - **Solution:** Packaged the VueJS application into a single, deployable SDK / Standalone Script. I implemented strict CSS encapsulation (preventing style leaks) and exposed a clean, minimal initialization API (window.AzyChat.init()). This ensured the chatbot integrated flawlessly into any external ecosystem without breaking the host site’s UI or logic.

## Result

Delivered an a11y-compliant, SEO-optimized corporate website. Furthermore, successfully shipped the AI Chat Bot as a robust, embeddable SDK, empowering the client to easily distribute their product to B2B partners.
