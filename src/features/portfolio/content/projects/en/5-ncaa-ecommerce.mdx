## Problem

The client needed a storefront that could handle products with multiple variants (size, color, quantity) and dynamic pricing, plus an internal system non-technical staff could use to manage that catalog without engineering help.

## Responsibilities

Built the storefront UI from Figma, including variant-based product pages, team-specific collections and cart checkout, and added social login (Google, Facebook). Configured and optimized technical SEO end to end — robots.txt, sitemap.xml, meta tags, structured data and PageSpeed — alongside the customer-facing admin system for product CRUD and page metadata.

## Result

Shipped both the storefront and the admin system as part of a 6-person team, with SEO groundwork in place before launch instead of bolted on after.
